Priority-Based Hospital Bed Allocation

Hospital beds are limited, but emergencies aren't. This system assigns beds using a priority queue — critical patients are treated first, and patients with the same priority are served on a first-come, first-served basis. The result: shorter waiting times and better bed utilization.

Get Started Learn More

About the System

Why a Priority Queue?

Hospitals can't scale beds instantly — so the order in which patients receive them matters.

🛏️

Limited Hospital Beds

Every hospital has a fixed number of beds. During surges, demand often outpaces supply, so allocation decisions must be fast and fair.

📊

Priority Queue Concept

Instead of a plain line, patients are placed in a queue ordered by medical urgency (Priority 1 = most critical, 5 = least urgent).

⏱️

FCFS Within Same Priority

When two patients share the same priority level, the one who arrived first is allocated a bed first — keeping the process transparent.

📉

Reducing Waiting Time

By always serving the most urgent case next, average waiting time for critical patients drops significantly compared to random assignment.

✅

Better Bed Utilization

Beds are freed and reassigned systematically, reducing idle capacity and making sure no bed sits empty while a critical patient waits.

🧩

Simple, Extensible Logic

The whole system is built on arrays and sorting — easy to understand today, and easy to connect to a real database tomorrow.
